# Knowledge base

Put **real, public maintenance documents** here (`.pdf`, `.txt`, `.md`), for example an equipment manufacturer's maintenance manual
or a public maintenance guide you are allowed to use. Check each document's licence before committing it to a public repository.

The app only quotes passages from these files with source and page. If this folder is empty, the dashboard says so and gives no guidance.
Do not add text you cannot attribute to a trustworthy source.
